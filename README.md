# CubeVibe

一个纯前端 3D 魔方模拟器，支持 **二阶、三阶和四阶**，用于自由练习、学习转动公式和观察还原过程。基于 HTML、CSS、JavaScript 与 Three.js，适配电脑和手机，无需后端或构建工具。

## 主要功能

- 拖动魔方转层、旋转视角与缩放。
- 随机打乱、根据当前状态自动复原、3D 箭头提示。
- 撤销、即时重置，以及手动练习的步数和计时。
- 各阶公式手册，包含符号演示、常用公式和复原技巧。
- 求解器按需初始化，在当前页面内缓存，切换阶数时复用。

## 使用方法

下载项目后，联网用浏览器直接打开 `index.html`，无需安装依赖。

1. 选择 **2 × 2、3 × 3 或 4 × 4**，点击「打乱」开始练习。
2. **电脑**：左键拖动色块转层，拖动空白或按住右键旋转视角，滚轮缩放；也可使用转层按钮。
3. **手机**：在「拧动魔方」模式拖动色块；切换「旋转视角」后单指转动视角、双指捏合缩放。
4. 遇到困难时点击「求助提示」查看下一步，或点击「自动复原」观看完整还原过程。
5. 打开「公式手册」学习符号与公式，手册演示不改变主魔方。

打乱后的首次手动转动开始计时；切换阶数或重置会清空本轮状态和统计。求解器首次使用需要准备，四阶耗时较长；刷新页面后需重新初始化。

## 转动符号

- `U / D / F / B / L / R`：上、下、前、后、左、右层。
- `'`：逆时针转动；后缀 `2`：转动 180°，如 `R'`、`R2`。
- 三阶 `M / E / S`：三个中间层。
- 四阶 `2R`：从右面数第二层；`Rw`：右侧两层一起转动，其他面同理。

方向以正对相应面观察为准，具体示范见公式手册。
